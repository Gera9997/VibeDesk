# ⚡ VibeDesk — Высокоскоростной Remote Desktop для своих

**VibeDesk** — персональный, легковесный и неограниченный аналог AnyDesk на C# (.NET 8) и DirectX 11, созданный для комфортной работы и учебы без подписок, банов и лагов.

---

## 🚀 Преимущества перед AnyDesk

1. **Никаких ограничений и подписок:** приложение полностью твоё, никаких тайм-аутов, предупреждений о коммерческом использовании и отключений посреди работы.
2. **Аппаратный захват экрана DirectX 11 (DXGI Desktop Duplication):** кадры захватываются прямо из видеопамяти GPU (до 60 FPS при нагрузке на процессор < 2%).
3. **Прямой UDP-транспорт (LiteNetLib):** видео передается без накопления очередей задержки (Unreliable Sequenced), управление мыши и клавиатуры — с гарантированной доставкой.
4. **Два режима подключения:**
   * **🛋️ По дивану (в одной квартире):** подключение по локальному IP (например, `192.168.1.50:15890`) с ультранизким пингом (~1 мс).
   * **🌐 Между квартирами (через интернет):** подключение по простому 6-значному коду (**Vibe ID**). Приложение определяет публичный IP:порт через STUN (Google STUN) и соединяется напрямую P2P.
5. **Синхронизация буфера обмена и горячие клавиши:** удобные кнопки для `Ctrl+Shift+Esc`, `Win-Key`, передачи буфера и полноэкранного режима.
6. **Портативный:** скомпилирован в единый автономный файл `VibeDesk.exe` — не требует установки и работает на любом ПК с Windows.

## 📦 Где находится исполняемый файл?

Готовый файл лежит в папке:
`c:\work\VibeDesk\publish\VibeDesk.exe`

Ты можешь скопировать этот один файл на флешку, залить в Telegram или облако и запустить на любом из своих компьютеров (ноутбук, домашний ПК, сервер).

---

## 🛠️ Как пользоваться

### 1. Запуск на компьютере-сервере (домашний ПК):
1. Запусти `VibeDesk.exe`.
2. В левой карточке **«ЭТОТ КОМПЬЮТЕР»** отобразится твой **Vibe ID** (например, `742 819`) и локальный IP.
3. Хост автоматически ожидает подключения на порту `15890`.

### 2. Подключение с ноутбука:
* **Если ты в другой квартире (через интернет):**
  1. Введи в поле справа 6-значный **Vibe ID** домашнего ПК (например, `742 819`).
  2. Нажми **«⚡ Подключиться»**.
  3. Произойдет автоматическое рукопожатие через глобальную сеть и установится прямой P2P туннель.
* **Если ты в той же квартире (на диване):**
  1. Введи локальный IP домашнего ПК (например, `192.168.1.100` или `192.168.1.100:15890`).
  2. Нажми **«⚡ Подключиться»** — видео пойдет напрямую по домашнему Wi-Fi/роутеру с пингом ~1 мс!

---

## ⌨️ Управление в окне сеанса

* **⛶ Полный экран:** кнопка на панели или клавиша `F11`.
* **📋 Буфер обмена:** кнопка на верхней панели мгновенно копирует текст из твоего буфера на удаленный ПК.
* **Ctrl+Shift+Esc / Win-Key:** кнопки быстрого вызова диспетчера задач и меню «Пуск».
* **Диагностика:** в реальном времени отображаются текущий **FPS**, **пинг (мс)** и битрейт (**Кб/с**).

## 💻 Сборка из исходников

Если захочешь что-то модифицировать в кодовой базе:
```powershell
# Обычный запуск для разработки
dotnet run

# Сборка единого портативного .exe
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./publish
```
