## Дорожная карта производительности (Performance Roadmap)

### Этап 1: Ликвидация сетевых заторов и параллелизация CPU (Quick Wins)
- [ ] **Token Bucket (Маркерная корзина) вместо секундного стопора:**
  - Замена блокировки отправки кадров при исчерпании лимита в текущей секунде на плавное микро-пакетирование (интервалы 10–20 мс).
- [ ] **Снятие затора In-Flight подтверждений (ACK bottleneck):**
  - Увеличение порога окна `inFlight` с 8 до 32+ полос (или привязка к `FrameId`), чтобы пинг 40–80 мс через Интернет не глушил генерацию кадров до 18 FPS.
- [ ] **Многопоточное сжатие полос (`Parallel.For`):**
  - Параллельное сжатие 8 полос на всех ядрах CPU с независимыми потоками сжатия, сокращающее время кадра с 30 мс до 4–7 мс.
- [ ] **Расширение потолка битрейта:**
  - Повышение лимита для хорошего интернет-соединения до 15–25 Мбит/с для устранения мыла и артефактов при динамичном движении.

### Этап 2: SIMD и оптимизация работы с памятью (Zero-Allocation Pipeline)
- [ ] **Устранение лишних копирований памяти при нарезке полос:**
  - Замена промежуточного `Graphics.DrawImage` для каждой полосы на прямое чтение строк пикселей из `fullData.Scan0` (Pointer Slicing) с передачей в энкодер.
- [ ] **Оптимизация клиентского декодера (`RemoteSessionWindow`):**
  - Переиспользование буферов декодирования, исключение создания сотен `MemoryStream` и снижение нагрузки на Garbage Collector (GC).
- [ ] **GPU DXGI Fast Path:**
  - Оптимизация захвата через DXGI без промежуточных софтверных ресайзов при 100% масштабе.

*(Фиксация Этапа 1 и Этапа 2 локальным коммитом в Git без отправки на сервер).*

- [ ] **Реализация альтернативного видеорежима:**
  - Аппаратное кодирование H.264 / Fast Stream (Windows Media Foundation / GPU NVENC/QuickSync/AMF).
- [ ] **Переключатель режимов в интерфейсе (UI Codec Switcher):**
  - Добавление переключателя в тулбар окна удаленной сессии:
    - *«Режим: Motion-JPEG (Турбо-полосы)»*
    - *«Режим: H.264 (Аппаратный видеопоток)»*
- [ ] **Информационный HUD сравнения производительности:**
  - Вывод в реальном времени текущего движка, реального FPS, битрейта (Кбит/с), RTT пинга и задержки кодирования (Encode Time ms), чтобы наглядно оценить разницу в плавности и нагрузке.
