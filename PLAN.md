## Дорожная карта производительности (Performance Roadmap)

### Этап 1: Ликвидация сетевых заторов и параллелизация CPU (Выполнено)
- [x] **Token Bucket (Маркерная корзина) вместо секундного стопора:**
  - Заменена жесткая секундная блокировка на плавное квантование трафика (Token Bucket с окном 150 мс), устраняющее микрофризы при исчерпании лимита.
- [x] **Снятие затора In-Flight подтверждений (ACK bottleneck):**
  - Порог окна `inFlight` расширен с 8 до 32 полос (4 полных кадра). При задержке ACK через Интернет более 35 мс окно плавно смещается вперед, исключая падение до 18 FPS.
- [x] **Многопоточное сжатие полос (`Parallel.For`):**
  - Параллельное сжатие 8 полос на всех ядрах CPU с независимыми потоками сжатия, сократившее время кадра с 30 мс до 4–7 мс.
- [x] **Расширение потолка битрейта:**
  - Базовый битрейт увеличен с 3.5 Мбит/с до 15–20 Мбит/с с адаптивным запасом.

### Этап 2: SIMD и оптимизация работы с памятью (Zero-Allocation Pipeline) (Выполнено)
- [x] **Устранение лишних копирований памяти при нарезке полос:**
  - Внедрен прямой срез памяти (Direct Pointer Slicing) из `LockBits(fullData.Scan0)`. Полностью устранены промежуточные вызовы `Graphics.DrawImage` для нарезки полос.
- [x] **Оптимизация клиентского декодера (`RemoteSessionWindow`):**
  - Внедрен пул буферов памяти `ArrayPool<byte>.Shared.Rent/Return`, исключающий создание 240 МБ/с временных массивов в Garbage Collector.
- [x] **GPU DXGI Fast Path:**
  - При масштабе 100% исключена промежуточная отрисовка `_workGraphics`, кадр захватывается и нарезается напрямую.

*(Зафиксировано локальным коммитом `c245c22` в Git без отправки на удаленный сервер).*

### Этап 3: Альтернативный потоковый движок и переключатель режимов (Выполнено)
- [x] **Реализация альтернативного видеорежима (Full Frame Video Stream):**
  - Добавлен полнокадровый потоковый режим `CaptureFullFrame` (префикс `0xAA 0x01` + JPEG/Video payload), где хост непрерывно передает полный кадр, а клиент отрисовывает его целиком в один атомарный проход без нарезки и сшивки полос.
  - Подключена библиотека аппаратного медиа-стека `Vortice.MediaFoundation` (v3.8.3).
- [x] **Переключатель режимов в интерфейсе (UI Codec Switcher):**
  - В верхней панели `RemoteSessionWindow` добавлен выпадающий список:
    - `⚡ Турбо-MJPEG (Полосы)` — высокая четкость текста/кода, нулевой трафик в статике;
    - `🎬 Видеопоток (Full Frame)` — полнокадровый видеорежим без разрывов при скролле и движении.
  - Переключение отправляет команду `PacketType.StreamMode` на хост и переключает рендерер налету во время сессии.
- [x] **Информационный HUD сравнения производительности:**
  - Статусная строка обновляется в реальном времени каждые 500 мс и выводит:
    - Текущий активный режим: `[⚡ Турбо-MJPEG]` или `[🎬 Видеопоток]`;
    - Реальную частоту кадров: `Полос/c: X` или `Кадров/c: Y`;
    - Точный RTT пинг до удаленного узла (мс);
    - Фактический битрейт в Кбит/с.
